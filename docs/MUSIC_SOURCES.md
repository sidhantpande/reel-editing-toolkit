# Music sources for future edits

The pinned `vendor/repos/muses` repository indexes music libraries. Its index is CC0, but linked recordings have their own terms. Verify the original track page for each use; a GitHub source index does not itself license audio.

| Source | Use |
|---|---|
| [Pixabay Music](https://pixabay.com/music/) | Search by instruments, mood and event. Save the exact creator/track URL and download record. |
| [Incompetech](https://incompetech.com/music/royalty-free/) | Instrumental catalog with track-level attribution blocks; copy the required credit into the delivered project's publishing notes. |
| [Free Music Archive](https://freemusicarchive.org/) | Check each recording's specific licence and attribution conditions. |
| [ccMixter](https://ccmixter.org/) | Remixes and instrumentals with per-track Creative Commons terms. |
| [Mixkit](https://mixkit.co/free-stock-music/) | Preview tracks and retain the applicable licence details. |
